## 0. 읽는 법

1. 화면 하나가 카드 하나다. 카드는 **화면 ID · 종류 · 상태 · 화면 요소 · 구역별 상태 · 분기** 순서로 적는다.
2. **분기 표가 이 화면의 입력 → 출력이다.** 왼쪽 칸은 사용자 동작이나 조건(입력), 오른쪽 칸은 그 결과로 가는 화면·상태(출력)다. 카드에 적힌 분기가 그 화면에서 갈 수 있는 길의 전부다.
3. **화면 ID**(S-xx, P-xx, D-xx, R-PDF)는 개발 명세·테스트·코드(`data-testid`)에서 같은 이름으로 쓴다.
4. **화면 요소**는 시안에 보이는 글자를 그대로 옮긴 것이다. 이름·대화·날짜·시각은 예시다.
5. 자유대화와 연습은 진행 화면 **12**, 끝 화면 **17**을 함께 쓴다. 요구사항·기능명세서의 21(연습 진행)은 12, 23(연습 끝)은 17이다.
6. 이 문서에 없는 화면 번호는 만들지 않는다.

## 1. 공통 규칙

### 탭 규칙

- 하단 탭 넷: 홈 04 · 자유대화 08 · 연습 18 · 기록 26
- 시작 조건 셋 — 기기 연결(연결됨) · 필수 동의 · 이전 활동의 종료 확인 — 중 하나라도 없으면 자유대화 · 연습 탭 잠김. 잠긴 탭을 누르면 이유 토스트 → 05(필수 동의가 없으면 02 관리)
- 활동 진행 중 · 종료 확인 중이면 자유대화 · 연습 탭 모두 → 12 활동 진행 (새 시작 없음)
- 공통 오류 · 로딩: API 실패 · 보호자 폰 인터넷 끊김은 화면 아래 토스트 "연결이 원활하지 않아요" + 「다시 시도」. 로딩 중엔 단추를 흐리게(스켈레톤 없음). 보내지 못한 요청은 보낸 것으로 표시하지 않는다
- 보호자 앱 조회 불가: 04 · 12에 "실시간 상태를 불러오지 못하고 있어요" + 마지막 확인 시각 · 상태. 현재 상태로 단정하지 않고, 다시 연결되면 실제로 받은 대화 글 · 기록으로만 채운다
- 알림 진입(FR-A10): 푸시를 누르면 최신 상태를 다시 조회 → 진행 중 12 / 기술 문제 종료 P2 → 17 / 그 밖의 종료 17 / 조회 실패 04(마지막 확인 시각 · 미확인). 오래된 알림 문구로 현재 상태를 덮어쓰지 않는다
- 앱을 닫는 것은 종료 요청이 아니다. 앱이 꺼져 있어도 기기 연결이 정상이면 활동 · 기록은 계속된다

### 계정 · 동의 · 아이

- 로그인은 구글 하나. 유효한 로그인 상태면 다시 묻지 않는다. 로그인 만료 → 01 → 재로그인 → 04
- 순서: 01 로그인 → 02 동의(처음 한 번 · 생성형 AI 고지 · 아이에게 할 말 1회) → 03 내 아이(처음 등록) → 04 홈. 아이가 이미 있으면 03 건너뜀
- 동의 4항목 모두 필수(음성 수집 · 글로 옮겨 저장 / 보호자 열람 / 리포트 생성 · 외부 전달 / 원음 보관). 항목마다 「자세히 보기 ›」(02-1). 네 개를 다 체크해야 「동의하고 계속」이 켜진다
- 동의 · 기록 관리(SET-00 → 02 관리): 체크를 끄면 철회(P8 확인 → 진행 중 활동 종료 요청 → 이후 수집 · 이용 중단 · 탭 잠김). 다시 넷 다 체크하고 「저장」하면 잠금 풀림. 기록 삭제는 대상(원음 · 대화 글 · 리포트) → P9 영향 안내 · 확인. 철회 전 기록은 남아 따로 지울 수 있고, 철회 뒤 도착한 자료는 저장하지 않는다
- 약관 개정: 동의에 약관 버전을 남기고 개정되면 다음 실행에 02 재동의
- 경계: 보호자 계정 1 = 아이 1 = 기기 1. 형제는 구글 계정을 따로 쓴다. 공동 보호자 · 전문가 계정 없음
- 아이 삭제(03 「삭제」 → P4): 아이와 그 아이의 기록 · 연습 목표 · 종료 표현을 함께 지우고 03 처음 등록으로. 동의와 기기 등록은 계정에 남는다. 진행 중이거나 종료가 확인되지 않은 활동이 있으면 삭제하지 않는다
- 계정 삭제(SET-00 → P7): 진행 중 활동은 종료 확인 뒤 삭제 → 01. 같은 구글 계정으로 다시 로그인하면 02부터

### 기기 · 활동

- 기기는 계정에 하나. 아이 기기 웹(D0)에 뜬 등록 코드를 05 → 05a에서 넣어 묶는다. 등록 뒤 기기 토큰으로 자동 연결. 새 기기를 등록하면 이전 등록은 무효
- 05의 세 줄: 기기 등록 · 기기 연결(연결됨 · 끊김 · 응답 없음 · 음성 서버 문제) · 인터넷 연결(내 폰). 판정 카드가 세 줄을 합쳐 한 문장으로 말한다. "연결됨"은 기기 연결이 실제로 유지되는 동안만
- 종료 표현(SET-01): 기본 "무중아 그만할래" 고정 + 아이별 추가 표현. 빈 값 · 중복은 저장하지 않는다. 저장한 표현은 다음 활동부터. 종료 표현이 종료의 유일한 방법은 아니다(말과 맥락으로 분명한 종료 의도도 종료)
- 시작: 08 · 18에서 시작 요청 → 12 "시작 요청됨 · 실행 확인 중" → 기기 안내가 확인되면 "참여 기다리는 중". 연습은 그 앞에 "상황 준비 중"(고른 목표 이름 · 「취소」). 별도 준비 화면 없음
- 진행 화면 12: 맨 위 상태 한 줄 + 시작 시각 · n분째, 아래 실시간 대화 글(무중 · 아이 · 시각 · 말하는 중). 연결 문제는 "잠깐 끊김" 구간 하나. 판정 결과 · 확률 · 점수 · 단계 · 목표 순번(n/N)은 보여 주지 않는다. 공백(4분 + 약 2분 자동 종료)은 화면에 따로 표시하지 않는다
- 끝내기: 12 「끝내기」 → P1 → 「네」 → 12 "끝내는 중" → 기기 종료 확인 → 17(기술 문제 종료만 P2 → 17). 종료 확인이 오지 않으면 12 "종료 확인 안 됨" + 마지막 확인 시각 + 원격 제어 한계 + 「상태 다시 확인」. 요청 접수나 시간 경과만으로 끝난 것으로 보지 않는다. 종료가 불분명한 동안 새 활동을 시작할 수 없다
- 아이 종료 표현 · 자동 종료 · 정상 마무리도 같은 "끝내는 중" → 종료 확인 → 17(팝업 없음). 참여 전 미참여는 P3 → 04(기록 없음)
- 17은 종료 사실과 기록 정리 상태(정리 중 · 끝 · 실패)만 보여 준다. 종료 사유 · 확보 범위 · 미확인 구간 · 장면 결과는 27에서 본다
- 연습: 18에서 목표 여러 개 선택 가능. 순서는 ★ 즐겨찾기와 담은 순서에 가중치를 둔 무작위. 목표 지우기는 길게 눌러 확인(P10)

### 기록 · 리포트

- 26 달력: 활동 있는 날 표시 → 그날 활동(종류 · 길이 · 중간에 끊김 · 기록 준비 중 · 생성 실패) → 27
- 27: 끝난 이유 칸, 연습은 목표별 장면 결과 칩 + 결과 문장 + 제공한 도움, 대화 기록 · 생활 팁 · 연습 목표 칸. 결과는 기록용 재판정을 따른다. 받지 못한 구간을 침묵 · 거부 · 실패로 채우지 않는다
- 리포트: 28 범위 → 만드는 중 → 29 리포트 확인(10개 항목 + 진단 결과 아님 고지) → PDF 저장 확인 시트 → 저장 → 26. 전달은 보호자가 직접 한다. 앱 안의 전송 · 공유 · 수신 확인은 없다
- 10개 항목: 1. 활동 개요 · 2. 관찰된 장면(인용) · 3. 연습 목표와 장면 · 4. 아동 정보 · 5. 최근 실제 경험과 출처 · 6. 주요 대화 내용 · 7. 살펴본 화용 행동 · 8. 제공한 도움 · 9. 과거 기록과의 차이 · 10. 제한사항. 미실시 · 자료 부족은 결측으로 표시

### 서버에 필요한 것

- 종료 확인: 아동 서비스가 기기 종료를 확인한 뒤에만 17 · 완료 알림으로 넘어간다. 확인 전에는 세션이 "끝내는 중"이고 새 활동을 막는다
- 종료 사유(end_reason): 정상 마무리 · 시작 전 아동 미참여(저장 안 함) · 아동 중단 · 보호자 중단 · 기술 문제 · 대화 거부 · 비정상 오디오 공백 지속 · 동의 철회. 27 끝난 이유 칸에 쓴다
- 동의 철회 · 기록 삭제 API(02 관리 · P8 · P9), 아이 삭제 API(P4), 계정 삭제 API(P7)
- 리포트: 10개 항목을 저장된 구조화 데이터 · 인용 · 재판정 값으로 만들고 결과 작업으로 상태를 조회한다(만드는 중 · 실패)
- 알림 페이로드에 sessionId와 상태 · 대화 내용은 넣지 않음 · 같은 사건은 한 번
- D0 등록 코드 발급과 기기 토큰 · Device(기기 코드 · 묶인 계정 · 기기 토큰 · 마지막 응답 시각)
- 세션에 목표 여러 개 싣기(목표 큐 · 가중 무작위 순서)
- 전사를 보호자 앱으로 실시간 전달(아동 서비스 → 보호자 서버 → 보호자 앱)
