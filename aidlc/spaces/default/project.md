## Corrections
- 모든 대화와 산출물은 한국어로 작성한다.
- 모든 질의응답을 기록한다. 내가 한 질문과 답변, 확인 요청, 선택지와 내가 고른 답, 수정 지시를 빠짐없이 해당 단계의 질문 파일에 남긴다.
- 기록은 AI-DLC가 정한 질문 파일 형식을 그대로 따른다. 형식에 없는 H2 제목(예: "이번 회차 기록")을 새로 만들지 않는다. 추가 기록이 필요하면 기존 항목 아래에 H3 이하로 덧붙인다.
- 입력 문서에 없는 값(시간값, 재시도 횟수, 판정 기준 등)은 지어내지 말고 질문한다. 미결 항목은 요구사항 입출력 명세 9장과 기술명세서 v1.1 16장을 따른다.
- 문서끼리 충돌하면 요구사항 입출력 명세 v1.0 → 기능명세서 → 기술명세서 v1.1 → 기획서·시나리오 순서로 따른다.

## Decided
- 서비스명 무중, 호출어 '무중아'
- 기술 스택과 확정 결정은 기술명세서 v1.1의 1장(확정 결정)과 4장(기술 스택)을 따른다. "Proposed"는 기본안이며 확정으로 보고하지 않는다.
- 그래프 DB는 Neo4j(공통 지식 전용, 읽기만). 아동 개인 데이터는 PostgreSQL에만 저장한다.
- 개발과 시험에는 합성 데이터와 성인 역할극 데이터만 쓴다.

## Forbidden
- 아동 명령으로 단계 건너뛰기
- 진단·점수·치료 효과 표현
- 실제 아동 자료를 입력이나 시험에 사용
- 서비스 안에서 리포트 전송, 전문가 계정
- Neo4j에 아동 발화·전사·목표 저장
