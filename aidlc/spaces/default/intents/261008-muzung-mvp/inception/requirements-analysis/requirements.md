# 요구사항 — 무중 MVP

> 이 문서는 요구사항을 새로 만들지 않는다. 주 입력 문서 `aidlc/spaces/default/knowledge/documents/02_요구사항_입출력명세_v1.4.md`(이하 **요구사항 v1.4**)의 카드 70건을 이 워크플로의 기준 목록으로 정리하고, 요구사항 분석 질문(`requirements-analysis-questions.md`의 Q1~Q12, 이하 `RA-Q<n>`)에서 정한 팀 결정을 덧붙인다.
>
> - **카드가 원본이다.** 각 요구사항의 트리거·선행 조건·입력·처리·출력·예외·분기는 요구사항 v1.4의 해당 카드(§8~§14)를 그대로 따른다. 카드와 원문이 다르게 읽히면 원문을 따른다(요구사항 v1.4 §0-1).
> - **완료 기준 = 수용 테스트 기준.** 카드의 '완료 기준'(기능명세서 v1.3 기능 ID의 검증 칸)을 수용 테스트로 쓴다(요청 진행 방식 2).
> - **하지 않는 것 = 구현 금지 사항.** 카드의 '하지 않는 것'은 구현하지 않는다(요청 진행 방식 2).
> - **ID는 추적 키다.** FR·NFR·화면(01~29·P·SET·D0·T19)·DATA-·EV-·J1~J7·기능 ID를 이후 설계·코드·테스트에서 그대로 쓴다. 이 문서는 `FR{n}` 형식으로 다시 번호를 매기지 않는다(요청 진행 방식 1).
> - **문서 우선순위.** 화면 설계 v1.6 → 요구사항 v1.4 → 기능명세서 v1.3 → ADR_2S → 기술명세서 v0.2 → AI 동작 명세 v0.1 순으로 앞의 문서를 따른다(팀 작업 방식 Q15).

## 의도 분석

| 항목 | 내용 | 근거 |
|---|---|---|
