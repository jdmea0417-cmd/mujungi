# 발견한 규칙 — 무중 MVP

> 인터뷰 Q14에서 사람이 강한 규칙으로 확정한 보안·개인정보 규칙 1~11번만 담았다. 기술 관례 12~23번은 `team-practices.md`의 `## Code Style`에 일반 관례로 두었다. 괄호 안은 규칙 번호와 근거 문서다.

## Mandated

- ALWAYS OpenAI·제브·구글·VAPID 키와 내부 공유 비밀, DB 접속 정보는 서버 환경 변수로만 넣는다(1번, 기술명세 §8·§11.3).
- ALWAYS 데모·시험·PoC에는 합성 데이터와 성인 역할극만 쓴다(3번, 기술명세 §8, 타당성 C-R01).
- ALWAYS 모든 요청에서 로그인한 보호자가 해당 아동·세션·기록·목표·리포트의 소유자인지 서버에서 확인한다(6번, 기술명세 §8).
- ALWAYS 기기 토큰은 해시로만 저장한다(10번, 기술명세 §8).

## Forbidden

- NEVER API 키, 내부 공유 비밀, `.env`, 인증서 개인 키를 저장소나 AI-DLC 입력에 넣지 않는다(2번, 기술명세 §2.4·§11.3).
- NEVER 실제 아동 자료, 실제 대화·전사를 저장소나 AI-DLC 입력에 넣지 않는다(3번, 기술명세 §2.4·§8).
- NEVER 비밀 키(OPENAI_API_KEY, JEV_API_KEY, GOOGLE_CLIENT_SECRET, VAPID_PRIVATE_KEY, INTERNAL_SHARED_SECRET 등)를 브라우저에 보내거나 프론트엔드 번들에 넣지 않는다. 단, 공개용 값인 VAPID 공개 키와 구글 클라이언트 ID는 예외다(4번, 기술명세 §8).
- NEVER 아동 발화 원문·전사·원음과 AI 요청·응답 본문을 애플리케이션 로그에 남기지 않는다. 로그에는 sessionId 같은 식별자만 남긴다(5번, 기술명세 §8·§11.4).
- NEVER GPT-Live 요청에 판정 기준·판정 라벨·확률·이전 판정 결과·보호자 입력 원문을 넣지 않는다(7번, 기술명세 §11.4, 타당성 C-T05).
- NEVER CI에서 실제 유료 AI API를 부르지 않는다. CI는 가짜 모델만 쓴다(8번, 기술명세 §10, ADR-002).
- NEVER 합성 데이터로 얻은 결과를 실제 아동 성능으로 보고하지 않는다(9번, 기술명세 §10).
- NEVER CSRF 보호를 끄지 않는다(10번, 기술명세 §8).
- NEVER `/internal/` 경로와 내부 서버 간 채널을 Nginx 밖으로 노출하지 않는다(10번, 기술명세 §8·§11.1).
- NEVER AI(무중) 출력 음성을 저장하지 않고, 아동 원음 바이트를 DB·로그·임시 파일에 두지 않는다. 아동 원음은 원음 보관 동의에 따라 정한 원음 저장소에만 둔다(11번, 기술명세 §2.3, ADR_2S DL-012-01/02).
