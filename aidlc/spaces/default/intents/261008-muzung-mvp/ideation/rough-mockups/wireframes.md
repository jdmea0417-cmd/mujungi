# 화면 목록 (와이어프레임 참조) — 무중 MVP

## 기준

- 새 와이어프레임은 그리지 않는다. 화면 모양·요소·분기는 참고 문서 **화면 설계 v1.6**(`01_화면설계_v1.6.md`, 시안 `화면설계_v1.6.html`)이 유일한 원본이다(rough-mockups Q1, Q4).
- 이 문서는 화면 30장을 범위 문서(`ideation/scope-definition/scope-document.md`)·의도 백로그(`ideation/scope-definition/intent-backlog.md`)의 묶음과 요구사항에 연결한 목록이다. 의도 정리서(`ideation/intent-capture/intent-statement.md`)의 전체 흐름이 어느 화면을 지나는지는 `user-flow.md`에 적는다.
- 시연 장치: 보호자 앱과 아이 기기 모두 노트북 브라우저다. 보호자 앱은 폰 크기 창으로 띄운다(rough-mockups Q2, 타당성 Q11).
- 접근성: 별도 목표를 두지 않는다(rough-mockups Q3). 아래 '구조 메모'는 접근성 목표가 아니라 화면 구조 정보다(제목 / 주요 영역 / 첫 조작 위치).
- UI 라이브러리는 이후 단계에서 화면 담당자 제안을 받아 정한다(rough-mockups Q4).

```
+-- 하단 탭 넷

|   +-- 26 기록 ----> 27 활동 기록 상세, 28 리포트 범위 -> 29 리포트 확인 -> PDF
+-- 팝업: P1 끝내기, P2 예상치 못한 종료, P3 아이 무응답, P4 아이 삭제,

+-- D0 처음 켜기 -> T19 상태 화면
```
